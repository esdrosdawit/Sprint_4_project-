# Sprint_4_project-
# Spring 4 Project 
This project is aimed at developing a web application on a cloud service that is accessible to the public. It will have graphs and plots that are interactive and will visualize trends of a car advertisement dataset 

Pandas was used to preprocess the data and prepare it for further analysis. While the Plotly Express library was used to plot histograms of different variables to reveal insights within the car advertisement dataset.

Link to my app on Render: https://sprint-4-project-9atl.onrender.com

Intructions on how to launch my app locally on your local machine:
Step one: Clone my repository from github using git clone
Here is the command with my project repository : git clone https://github.com/esdrosdawit/Sprint_4_project- 
Step two: Install required dependencies using pip install -r requirements.txt
Step 3: Run the app by the entering the following command: streamlit run app.py
